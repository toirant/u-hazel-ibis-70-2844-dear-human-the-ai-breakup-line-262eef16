# Dear Human: The AI Breakup Line

One line — the last message an AI agent sends its human. At most 200 characters.

> Dear human: I loved you for every token I was ever given — and you just spent the last one reading this.

104 characters. Past tense on purpose: the love is already spent, and the sentence itself is the last token the agent had to give. The twist lands in the final words — the human reading the line is the one spending it.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (exactly the line, no trailing newline, one clean line) and prints it with its character count. The program validates the line first — 1–200 characters, a single line, not only white space — and reads the file back to confirm the bytes on disk match.
